# Credo (CRD)

Moneda digital elástica sin blockchain ni gas.

- **Nombre:** Credo
- **Símbolo:** CRD
- **Concepto:** Dinero digital real, usable, seguro con criptografía estándar.
- **Emisión:** Automática según demanda, con límites anti-inflación (±2%/mes).
- **Seguridad:** Firmas Ed25519 + nonce + hash encadenado + nodos replicados.
- **Licencia:** MIT

Ver [SPEC.md](SPEC.md) para los detalles técnicos y económicos.
